# Multi-Task Clicker

Windows-кликер с последовательностью координат и глобальной клавишей F6.

## Возможности

- Добавление текущей позиции мыши одним нажатием кнопки.
- Любое количество точек.
- Отдельная задержка после каждого клика.
- Последовательность повторяется по кругу.
- F6 — старт/стоп.
- Сохранение и загрузка списка точек.
- Сборка EXE автоматически через GitHub Actions.

## Сборка на GitHub

1. Создай новый GitHub repository.
2. Загрузи в него всю эту папку, сохранив структуру `.github/workflows/build.yml`.
3. Открой вкладку **Actions**.
4. Выбери **Build Windows EXE**.
5. Нажми **Run workflow** (или дождись автоматической сборки после push).
6. Открой завершившийся workflow и скачай artifact **MultiTaskClicker-Windows**.

## Локальная сборка

MinGW g++:

```bash
g++ src/main.cpp -std=c++17 -O2 -mwindows -municode -o MultiTaskClicker.exe -luser32 -lcomctl32
```

## Использование

1. Запусти `MultiTaskClicker.exe`.
2. Поставь мышь в нужную точку.
3. Нажми **«Добавить текущую позицию»**.
4. Повтори для всех точек.
5. Укажи задержку в миллисекундах перед добавлением каждой точки.
6. Нажми **F6** или кнопку запуска.

Например:

Точка 1 → клик → 100 мс → точка 2 → клик → 500 мс → точка 3 → клик → 1000 мс → снова точка 1.
